# TypeScript 基本拡張

このテンプレートは `0BSD` ライセンスです。

以下を示しています：

- コマンド登録；
- キーバインディングと結果グリッドのアクション寄与；
- ホストAPIを通じた結果グリッドの読み取りとクリップボード書き込み；
- テーマとSQL方言の登録；
- ローカル開発用のフィクスチャとログ。

SDKリポジトリのルートからローカル開発ホストを起動します：

```sh
node bin/irodori-extension-dev.mjs templates/typescript-basic --once
```
