# パッケージング

Irodori製品向けのリリースおよびパッケージマネージャーテンプレート。

製品固有のテンプレートは製品ディレクトリ内にあります：

- `irodori-table/`：Irodori Tableのデスクトップパッケージングメタデータ。

生成されたリリース資産は製品リポジトリに保持してください。再利用可能な提出テンプレートやパッケージングポリシーはここに保持し、すべてのIrodoriアプリが同じリリースルールに従うようにします。
