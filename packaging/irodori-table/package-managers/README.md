# Irodori Table Package Manager Templates

Submission templates for Irodori Table package managers.

Use them only after a GitHub Release has final assets and checksums.

## Fill in

- version
- tag
- asset URL
- sha256
- installer type
- OS requirements
- signing/notarization status

Do not submit templates with placeholders or draft-release URLs.
