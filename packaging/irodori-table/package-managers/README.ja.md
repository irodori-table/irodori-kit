# Irodori Table パッケージマネージャーテンプレート

Irodori Table パッケージマネージャー用の提出テンプレートです。

GitHub リリースに最終的なアセットとチェックサムが揃ってからのみ使用してください。

## 記入項目

- バージョン
- タグ
- アセットのURL
- sha256
- インストーラーの種類
- OS要件
- 署名／公証の状況

プレースホルダーやドラフトリリースのURLが含まれるテンプレートは提出しないでください。
